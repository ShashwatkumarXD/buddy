BUDDY GUIDE
===========

A Pokémon that lives on top of your windows. It wanders along the bottom of the
screen and acts as your laptop's "soul": when CPU or RAM gets high enough to make
the laptop lag, it gets stressed and shows a Matrix-style CPU/RAM readout.


INSTALL (once)
--------------
  Windows (PowerShell):
    irm https://raw.githubusercontent.com/ShashwatkumarXD/buddy/main/install.ps1 | iex
  macOS / Linux:
    curl -fsSL https://raw.githubusercontent.com/ShashwatkumarXD/buddy/main/install.sh | bash

No Python or Git needed: it fetches a private Python (via uv) and Qt, sets up the
`buddy` command, turns on start-at-login, offers to connect your AI agents, and
starts your buddy. Run it again any time to update; settings are kept.
On Linux it also offers to install the few system libraries Qt needs.


COMMANDS
--------
  buddy run               Start your buddy (only one runs at a time). It keeps
                          running after you close the terminal, until `buddy stop`.
                          (`buddy run --foreground` stays attached, to watch for errors.)
  buddy stop              Stop it
  buddy choose <name>     Switch Pokémon, e.g. `buddy choose charmander`
                          (no name = it asks). A running buddy switches instantly.
                          Names are English, any case; spaces are fine (mr mime).
  buddy config            Open the settings file in your editor; it is checked
                          when you close the editor and a running buddy reloads.
  buddy autostart on      Start buddy automatically when you log in
  buddy autostart off     Don't start at login
  buddy agents on         React to every installed AI agent (Claude Code, Gemini CLI, Codex):
                          adds two hooks to each one's settings, keeping everything else;
                          a backup is saved next to each file
  buddy agents on gemini  Just one agent (claude, gemini or codex)
  buddy agents off        Stop reacting (removes only buddy's hooks)
  buddy claude on        Same as `buddy agents on claude`
  buddy claude off        Same as `buddy agents off claude`
  buddy guide             Show this guide
  buddy --help            Short list of commands


PLAYING WITH IT
---------------
  Click it                ❤️  it feels loved and does a little hop
  Click, hold and drag    carry it anywhere; let go and it falls back down,
                          looking confused ❓
  Shake it while holding  😵‍💫 it gets dizzy: a spinning scribble, even after it lands
  Walking into an edge    turns around (sometimes confused ❓)
  Laptop under load       💢 it stops and fidgets, and a green Matrix panel shows
                          CPU % and RAM %. Hidden again once things calm down.
  Clicks next to it go through to the window underneath.


AI AGENTS (Claude Code, Gemini CLI, Codex)
------------------------------------------
After `buddy agents on` (the installer offers this when it finds one):
  You send a prompt       it hurries to a spot near the right of the screen and
                          shows its thinking bubble (a book flipping its pages)
  The agent finishes      ❗ bubble and three hops on the spot, then back to wandering
  You stop it early       it gives up thinking after 10 minutes, or at your next prompt
Restart open agent sessions after turning this on or off. Codex asks you to approve
new hooks once: run /hooks inside Codex. With several agents busy, the latest event wins.
  Files: ~/.claude/settings.json, ~/.gemini/settings.json, ~/.codex/hooks.json


SETTINGS  (~/.config/buddy/config.toml, edit with `buddy config`)
--------
  pokemon = "pikachu"     Set this with `buddy choose`, which also downloads the sprite
  style = "hgss"          hgss = HeartGold/SoulSilver follower sprites (#1–493)
                          gba  = Mystery Dungeon style sprites (nearly every Pokémon)
                          ds   = Black/White battle sprites
                          After changing style, run `buddy choose <name>` again.
                          hgss falls back to gba for Pokémon after #493.
  scale = 2               Size. Whole numbers keep pixel art crisp (2 ≈ 64 px,
                          3 ≈ 96 px). Allowed 0.5–6. Bubbles follow at half this.
  walk_speed = 20         Pixels per second (1–500)

  [stress]                When does it get stressed? (percentages)
  cpu_enter = 85          Stressed when average CPU over the window reaches this…
  ram_enter = 90          …or average RAM reaches this
  cpu_exit = 70           Calm again only when CPU stays below this…
  ram_exit = 85           …and RAM stays below this, for a whole window
  window_seconds = 5      Length of that window in seconds (1–60)
  Each *_exit must be lower than its *_enter.

Try the stress look (all cores busy for 25 seconds):
  for i in $(seq $(nproc)); do timeout 25 sh -c 'while :; do :; done' & done


FILES
-----
  Settings      Linux ~/.config/buddy · macOS ~/Library/Application Support/buddy
                Windows %APPDATA%\buddy
  Sprites/logs  Linux ~/.cache/buddy · macOS ~/Library/Caches/buddy
                Windows %LOCALAPPDATA%\buddy\Cache  (safe to delete)
  Program       Linux ~/.local/share/buddy · macOS ~/Library/Application Support/buddy
                Windows %LOCALAPPDATA%\buddy  (buddy, its Python and uv)
  Login start   Linux ~/.config/autostart/buddy.desktop
                macOS ~/Library/LaunchAgents/com.buddy.pet.plist
                Windows registry: HKCU\…\CurrentVersion\Run → Buddy


TROUBLESHOOTING
---------------
  "Buddy is already running"     `buddy stop`, then `buddy run`
  "No sprites cached for …"      `buddy choose <name>`
  "Qt needs some system libraries" (Linux)  run the sudo apt line it prints
  "could not connect to display" (Linux)   sudo apt install xwayland
  Settings error                 `buddy config` shows the bad line; fix it and save
  Not there after login          journalctl --user -b | grep -i buddy
  Doesn't react to your agent    `buddy agents on`, then restart the agent (Codex: approve via /hooks)
  `buddy: command not found`     add ~/.local/bin to PATH, or use ./.venv/bin/buddy


UNINSTALL
---------
  buddy agents off
  buddy stop
  buddy autostart off
  Then delete the folders listed under FILES and the `buddy` command
  (~/.local/bin/buddy, or %LOCALAPPDATA%\buddy\bin on Windows).
